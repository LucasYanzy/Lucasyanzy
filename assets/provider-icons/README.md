# Provider marks

Vector marks used on the AI usage card (`.github/scripts/ai_usage_card.py`), taken unchanged from
[Lobe Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg` 1.95.1, MIT licence),
except that the white rounded-square background of the Codex mark is removed.

The marks belong to their owners (Anthropic, OpenAI, Google, Cursor, DeepSeek, Moonshot AI, GitHub,
OpenCode). They are only used here to label which provider a share of usage belongs to.
